# Protection tables. Data only, no logic. Sections are [name], entries are one
# per line, # starts a comment.
#
# protected-paths      never removed, neither the path nor anything under it
# system-fast          glob patterns consulted during cleanup, a blanket is correct here
# system-critical      exact bundle ids that must never be uninstalled, must be exhaustive
# apple-uninstallable  Apple apps a user actually installed, exempt from the com.apple blanket
# data-protected       third-party apps holding credentials, sessions, or live databases
#
# Bundle matching is case-sensitive glob. macOS ships inconsistent casing across
# releases, so add both forms exactly as the drift audit prints them.
